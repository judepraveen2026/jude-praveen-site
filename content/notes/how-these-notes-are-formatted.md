This is a long sample note. It isn't a real post. It exists to show how longer writing looks in the reader, so every kind of formatting a post might use appears at least once below.

## Headings

Second-level headings, like the one above, split a long post into sections. They're set in the same serif as the title, just smaller.

### Smaller headings

A third-level heading works for a sub-point inside a section. It's best used sparingly.

## Paragraphs and links

Body text is set in a clean sans serif at a comfortable reading size, with enough space between lines that a long paragraph doesn't feel like a wall. Links look [like this one, which goes to the Projects page](/projects), and links to other sites open the same way, like [the Purdue University homepage](https://www.purdue.edu).
